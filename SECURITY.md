# Security policy

Verkéier is under active development. Security fixes are made on `main`; no
published app version has a separate maintenance branch yet.

Please [report vulnerabilities privately](https://github.com/pedrodsac/Verkeier/security/advisories/new).
Do not include credentials, personal location data, or exploit details in a
public issue. Include the affected version or commit, steps to reproduce, and
the impact in the private report.

If you find an exposed provider credential, revoke or rotate it with the
provider; deleting it from a new commit does not remove it from Git history.
