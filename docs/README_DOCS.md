# Docs Folder

Place these files in the repository's `docs/` folder next to the existing `PRD.md`.

Expected folder:

```text
docs/
├── PRD.md
├── ARCHITECTURE.md
├── CODEBASE_RULES.md
├── DATA_SOURCES.md
├── SUBAGENT_POLICY.md
├── MVP_CHECKLIST.md
└── CODEX_GOAL_PROMPT.md
```

Use `CODEX_GOAL_PROMPT.md` as the short `/goal` prompt.

The PRD remains the main product source of truth. These files exist to keep the build prompt short and make implementation rules explicit.
